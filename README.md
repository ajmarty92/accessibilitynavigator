## Twitter/X account monitor (Android)

A separate, personal side-project living in this repo: a way to follow a
hand-picked list of X/Twitter accounts and see their posts — with rich
push notifications — without ever opening X itself.

- [`docs/twitter-monitor-contract.md`](docs/twitter-monitor-contract.md) — the shared API/FCM contract
- [`backend/`](backend/README.md) — self-hosted Node/TypeScript scraper + push service
- [`android-app/`](android-app/README.md) — native Kotlin/Jetpack Compose app (dark-mode only)
